# Coupling-D6C real persistent mechanism gate

D6C is a development-only mechanism validation for the persistent-instrumented path. The implementation phase is no-model: it does not inspect an installed RWKV source, import the external RWKV model or Torch, access weights, load a model, or execute a forward call.

The future real gate is frozen to two non-Core shapes. Each shape receives one unscored persistent-OFF precondition followed by four fixed three-route rounds. The first three rounds form the complete three-route Latin cycle; the fourth is a preregistered repeat of the first order. The only routes are persistent OFF, persistent zero, and persistent active-synthetic; there is no raw-original route. This yields 13 calls per shape and 26 total calls.

The active route uses the deterministic synthetic probe already classified as mechanism-only and not a Self representation. Eight active calls must each visit all 32 post-FFN residual sites and apply once at frozen zero-based index 15, producing exactly 256 callback invocations and eight applications. The index is a preregistered midpoint mechanism probe, not a layer chosen from observed effects.

The transformed methods and dispatcher are installed once before the first future model forward and retain fixed identities for the entire 26-call lifecycle. Route selection is context-local, OFF and zero do not construct or call the probe, and runtime forward performs no model attribute switching.

The checked-in execution entry remains closed until a later message exactly matches the frozen execution authorization, a commit-bound machine authorization is created, and the single-use environment lock is set. It uses a unique authorization path and output directory, consumes the claim before model configuration, weight verification, or loading, and persists a failure with the claim consumed. A successful mechanism result could only open a separate D6D design review; it cannot establish a Self effect.

D5C, P1, and P2 remain stopped without rerun. This phase does not authorize D6C execution, D6D/D6E, formal data, real layer selection, a real Self projection, a Self effect conclusion, a Self Updater, or an automatic rerun.
