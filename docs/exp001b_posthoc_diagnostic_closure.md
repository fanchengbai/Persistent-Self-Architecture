## 1. 闭环结论

EXP-001B 的冻结确认性决定维持：Gate 2 与 Gate 4 均为
`revise_or_stop_measured_supplemental_control_failure`。后验诊断 v01–v06
没有把失败改写成通过，也没有授权自动重跑。

诊断已经把控制失败拆成两个性质不同的部分：

1. `random_matched` 中有 93 条首 token 损坏，属于广泛的随机状态破坏；
2. 非随机状态中有 22 条严格前缀失败，但它们全部直接输出了正确答案，属于
   `>\n` 协议边界上的格式偏差，而不是观察到的语义答错。

因此，EXP-001B 的严格控制门仍然失败；同时，后验语义影子指标表明非随机条件
下 672/672 条控制记录保持语义成功。这两个陈述必须并列保留，不能用其中一个
覆盖另一个。

## 4. 最终控制诊断

### 4.1 严格前缀分类

768 条同步能力控制中：

- 严格成功：653/768（85.03%）；
- 严格失败：115/768；
- 正确答案提前输出：22；
- 首 token 损坏：93；
- 错误答案提前输出：0；
- 其他未分类异常：0。

93 条首 token 损坏全部来自 `random_matched`。22 条正确答案提前输出全部来自
非随机状态条件，涉及 7 个 source samples。

### 4.2 语义影子指标

语义影子指标仅用于解释，定义为“严格前缀成功，或在 `>` 后立即输出正确答案
代码”。它不是确认性端点。

| 范围 | 严格成功 | 语义影子成功 | 未恢复失败 |
|---|---:|---:|---:|
| 全部条件 | 653/768（85.03%） | 675/768（87.89%） | 93 |
| 非随机条件 | 650/672（96.73%） | 672/672（100%） | 0 |
| `random_matched` | 3/96（3.13%） | 3/96（3.13%） | 93 |

这说明自然状态路径的已观察失败是协议格式敏感性；随机状态路径则是真实而广泛的
输出破坏。

### 4.3 来源因素与任务类型

只有 7 个 source samples 出现非随机格式事件，统计功效很低：

- 来源组合全局条件精确检验：`p = 0.8307`；
- 来源因素 0 Fisher 双侧检验：`p = 0.4353`；
- 来源因素 1 Fisher 双侧检验：`p = 1.0000`；
- 来源因素交互条件精确检验：`p = 1.0000`；
- 任务类型全局条件精确检验：`p = 0.2074`。

所有 95% Wilson 区间明显重叠。结果既不能证明因素完全无影响，也不能支持稳定
的主效应、交互或任务类型效应。所有 p 值均为未做多重性校正的后验描述。

## 5. State-norm 诊断

5,120 条 matched-context 记录全部至少触发一次组件告警，共 92,149 个组件告警。
告警比率集中在轻微超过阈值的范围，而不是少量极端爆炸；8 个状态路径在全部
5,120 条记录上持续告警。最合理的诊断是阈值校准分布与正式输入形状存在系统性
错配，但冻结规则要求零告警，因此测得的门失败不能被后验取消。

## 6. 为什么在 v06 停止后验诊断

冻结控制记录只保存以下前缀字段：

- `text`；
- `token_ids`；
- `greedy_token_ids`；
- `greedy_exact`；
- `roundtrip_exact`。

它们没有保存逐 token logits、log-prob、排名、top-k 或分数 margin。因此无法从
现有数据重建“换行 token 相对正确答案 token 差多少”。继续对相同记录切片不会
产生这项缺失证据，反而会增加后验选择风险。

停止条件已经满足：

1. 所有 115 条前缀失败均已分类；
2. 非随机语义错误数已确定为 0；
3. 小样本因素线索已给出区间和精确检验；
4. state-norm 告警模式已定位为系统性轻微越界；
5. 剩余关键问题需要未记录的模型分数，必须通过新的前瞻性实验回答。

## 7. 可支持与不可支持的陈述

当前证据支持：

- 随机匹配状态会严重破坏控制输出；
- 非随机状态路径在这批控制上没有观察到语义答案错误；
- 严格 `>\n` 协议对部分自然状态样本存在格式敏感性；
- 既有 state-norm 阈值不适配本次正式形状分布。

当前证据不支持：

- 把 EXP-001B Gate 改写为通过；
- 声称来源因素或任务类型有稳定显著效应；
- 声称格式失败的 logit margin 很小或很大；
- 用后验语义指标替代冻结确认性指标；
- 自动重跑 EXP-001B 或用相同测试集调参后再次声称确认性结果。
