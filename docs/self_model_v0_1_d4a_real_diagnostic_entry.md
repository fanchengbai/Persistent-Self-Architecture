# Self Model v0.1 D4A：真实最小诊断入口

## 本轮范围

本轮只实现真实 2.9B D4A 入口及其安全边界，不授权执行。入口复用已通过
fake 与服务器源码静态门的三路九调用核心：原始方法、无注入重编译 G0、
OFF-G2。夹具固定为 token `[2764]`、`state=None`、`full_output=false`，不设置或
丢弃预热。

## 单次执行边界

未来执行需要同时满足：干净的 `main`、固定配置和模型资产、精确环境锁、精确的
项目负责人授权文本及其机器授权文件。机器授权必须绑定最终 Git commit 和配置
digest。输出目录必须为空；claim 在权重校验、模型加载和推理之前独占创建。
机器授权一经创建即阻止入口自动再次启动；claim 创建后的完成或异常都会消费本次
机会，异常写入 `failure.json`，不得自动重跑。若在 claim 前因源码锁等前置条件
失败，机器授权仍会保留并阻止自动重试。

## 结果边界

诊断只记录九次调用的 logits/state digest、同路线九组比较、跨路线二十七组比较
及分类。它不重跑 D4 六单元，不修改 D4 失败状态，不实现 active injection、
Self projection、层选择或效果实验，也不授权 D5。

当前 `execution_authorized_at_implementation=false`。无模型静态复验通过后仍需
项目负责人逐字确认配置中的新授权文本，才允许创建机器授权并单次执行。
