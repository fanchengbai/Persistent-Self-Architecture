# Persistent Self Architecture

> 如果一个智能体每次开始对话都像刚刚“出生”，它再聪明，也很难真正成为一个持续存在的个体。

## 这个项目想做什么？

今天的大语言模型很擅长回答问题、编写代码和分析世界，但它们通常缺少一种重要的东西：

**一个能够跨越时间持续存在，并真正影响未来行为的内部“自我状态”。**

它们可能记得你说过什么，也可以按照提示扮演某个角色，但这并不一定意味着它们拥有一个稳定的内部立场。删除提示词、清空上下文或换一个会话之后，所谓的“身份”往往就消失了。

这有点像一个能力很强、知识很多，却每天早晨都会失忆的人：

- 他知道世界是什么样的；
- 但不一定记得自己是谁；
- 不一定记得自己长期想做什么；
- 也不一定知道自己的想法为什么发生了变化。

Persistent Self Architecture（PSA）想研究的是：

> 能否为人工智能设计一种持续、自我更新并具有因果作用的 Self Model，使它不只理解世界，也能维持和理解自己的状态？

## 为什么普通记忆还不够？

记忆保存的是：

```text
“我以前选择过数学。”
```

Self State 更接近：

```text
“长期经验使我形成了探索数学的稳定倾向，
这个倾向会影响我之后如何选择目标。”
```

两者的关键区别不在于文字怎么写，而在于是否真的影响行为。

如果删除 Self State，智能体的行为应当发生系统性变化；如果交换两个智能体的 Self State，它们的部分行为倾向也应随之迁移。否则，所谓的 Self 可能只是一段描述漂亮的提示词。

## 我们想验证什么？

项目关注可以观察、可以干预、也可以被证伪的问题：

- **身份连续性**：同一个智能体长期运行后，是否仍保持可识别的身份？
- **长期目标**：经过无关任务和环境干扰后，它能否继续原来的目标？
- **个体分化**：相同模型经历不同事件后，是否会形成不同的发展轨迹？
- **自我更新**：它能否根据经验改变，同时不发生毫无理由的身份漂移？
- **元认知**：它是否知道自己什么时候不确定、能力不足或需要进一步探索？
- **因果作用**：修改、删除或交换 Self State，是否会可重复地改变行为？

这里最重要的词是：**因果**。

我们不仅想让模型“说自己是谁”，还想知道这个内部状态是否真的参与了决策。

## 初步构想

传统语言模型通常可以被简化为：

```text
输入 → 世界建模 → 推理 → 输出
```

PSA 希望探索另一种结构：

```text
                 输入与经历
                      |
          +-----------+-----------+
          |                       |
          v                       v
     World Model              Self Model
     理解外部世界             维持内部状态
          |                       |
          +-----------+-----------+
                      |
                 耦合与决策
                      |
                 行动与反馈
                      |
             更新 World 与 Self
```

首版 Self State 被刻意限制在少数字段：

- 身份锚点；
- 当前目标；
- 稳定偏好；
- 置信度；
- 能力估计；
- 不确定性与内部冲突。

它不直接包含整段事件记忆；事件仍由独立的 Memory 模块负责。不同字段采用不同更新速度：当前目标可以快速变化，偏好和能力估计缓慢变化，身份锚点则需要更强的保护和更充分的更新证据。

## 为什么从 RWKV 开始？

项目计划首先使用 RWKV-7 0.4B 进行小规模实验。

RWKV 天然具有随序列演化的 recurrent state，适合研究内部状态如何被保存、恢复和改变。我们将尝试：

- 保存和恢复 state；
- 探测 state 中包含的信息；
- 交换两个运行轨迹的 state；
- 对 state 进行插值、扰动和消融；
- 观察这些操作是否会导致行为迁移。

先用小模型验证假设，再决定是否扩大模型规模。实验得出否定结果，同样是有价值的研究结论。

## 这个项目不是什么？

PSA 不试图宣称“创造意识”，也不判断机器是否拥有主观体验。

这些问题目前缺少统一、可操作的科学定义。项目关注的是更具体的工程与研究问题：

```text
持续内部状态
        +
Self Model
        +
可验证的行为影响
```

我们研究的是类似身份连续、目标保持、自我校准和个体分化的行为机制，而不是给机器贴上“有意识”的标签。

## 项目愿景

大模型的发展通常被描述为：

```text
更多参数 + 更多数据 + 更多算力
```

PSA 想探索另一条互补路线：

```text
更好的内部结构
        +
持续的状态演化
        +
可审计、可干预的自我模型
```

长期来看，我们希望回答：

> 当人工智能不再只是一次次响应输入，而是能够带着自己的历史、目标和能力判断继续前进时，它会不会表现出一种不同于传统 Agent 的智能？

答案可能是“会”，也可能是“不会”。无论是哪一种，都需要通过实验，而不是通过想象来决定。

克隆项目后，可在 Linux 云服务器的项目根目录执行：
